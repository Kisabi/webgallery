# Технічна документація проєкту: WebGallery

## Анотація

Цей проєкт є серверним API-застосунком, реалізованим на платформі Node.js. Архітектурна модель побудована на принципах розділення відповідальності (Layered Architecture: Controller-Service-Repository), що забезпечує модульність та легкість супроводження коду. Взаємодія з базою даних здійснюється за допомогою ORM Prisma.

## Стек технологій

- **Середовище виконання:** Node.js
- **Система керування базами даних (ORM):** Prisma
- **Тестування:** Jest (Unit/Integration Testing)
- **Архітектурний патерн:** Controller-Service-Repository

## Структура проєкту

Вихідний код організовано за функціонально-шаровим принципом:

```text
src/
├── controllers/   # Обробка HTTP-запитів та формування відповідей
├── services/      # Бізнес-логіка застосунку
├── repositories/  # Робота з базою даних
├── routes/        # Маршрутизація API-запитів
└── prisma/        # Схема даних та міграції

tests/             # Автоматизовані тести
```

### Опис директорій

| Директорія | Призначення |
|------------|------------|
| `src/controllers` | Реалізація логіки обробки HTTP-запитів та формування відповідей |
| `src/services` | Шар бізнес-логіки застосунку |
| `src/repositories` | Рівень абстракції даних, що взаємодіє з базою даних |
| `src/routes` | Конфігурація маршрутизації API-запитів |
| `tests` | Набір тестів для верифікації функціональності |
| `prisma` | Конфігурація схеми даних та керування міграціями |

## Розгортання

### 1. Клонування репозиторію

```bash
git clone https://github.com/Kisabi/webgallery
cd PRACTICE_VARCHAK
```

### 2. Встановлення залежностей

```bash
npm install
```

### 3. Конфігурація

Створіть файл `.env` у кореневому каталозі проєкту та визначте необхідні змінні середовища, зокрема:

```env
DATABASE_URL=your_database_connection_string
```

### 4. Міграція бази даних

```bash
npx prisma migrate dev
```

### 5. Запуск застосунку

```bash
npm start
```

## Верифікація коду

Для проведення автоматизованого тестування реалізованих компонентів використовується фреймворк Jest.

Запуск тестів:

```bash
npm test
```
